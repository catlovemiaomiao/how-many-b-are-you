# 你今天几 B？

五位呆萌监考员陪玩的脑力小测。五套原创题，共 80 题；轻快局做一套 16 题，认真局做连续两套 32 题。手机和桌面浏览器都能使用，交卷后可查看解析、生成竖版 PNG 结果海报。

## 在线试玩

[打开呆萌监考团](https://catlovemiaomiao.github.io/how-many-b-are-you/)。站点由 GitHub Pages 托管，不需要自己的服务器。结果和答题进度只保存在当前浏览器，没有账号、统计脚本或成绩上传接口；朋友收到的是测试网址，不会看到你的本地结果。海报可以下载或用手机系统分享。

## 打开试玩

在 Mac 上双击 `start.command`。它会启动只监听本机的临时网页，并自动打开浏览器；关闭终端窗口即可停止。也可以在本目录运行 `python3 local_server.py`。本机运行不需安装依赖、不连外网、不上传答案。

如果系统阻止首次双击，可在 Finder 里右键选择“打开”，或用终端运行上面的命令。

## 关于 B 值

**当前 B 是娱乐档位，不是智商、脑参数量，也不是与模型同题实测后的等效值。** 页面和结果海报都会显示这点。真正的成绩是答对数与分项答对数；B 称号按公开、固定的正确率区间生成。题型依据、规则和后续验证边界见 [参考基准与分档说明](calibration/REFERENCE_METHOD.md)。

## 题目和图片

- 题库源文件：`calibration/questions.json` 和 `calibration/additional_questions.json`。修改后运行 `python3 scripts/build_questions.py`，它会检查题数、分类与答案位置，并更新 `questions-data.js`。
- `assets/` 中的五张形象来自用户提供的图片，用作本站贴纸印花。公开展示不代表授权他人另行使用这些图片。当前没有为它们编造实际智能体姓名。
- 进度和最近一次结果只保存在当前浏览器的本地存储中。页面不需要账号或外部接口。
